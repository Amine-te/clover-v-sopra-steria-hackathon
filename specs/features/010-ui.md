# 010 UI

- **Status:** Draft
- **Owner:**
- **Needs:** 000 (mocks first)

## Summary

A Streamlit app for the caregiver, plus views for the other recipients.

## Inputs and outputs

- In: recordings, follow-up answers, report requests.
- Out: timeline view, follow-up prompts, mock messages, report download.

## Acceptance criteria

- **F010-AC1:** The caregiver can record a report and see the extracted facts.
- **F010-AC2:** Follow-up questions appear in the app and can be answered or skipped.
- **F010-AC3:** A timeline view shows Observations in time order.
- **F010-AC4:** Mock messages are shown per recipient role.
- **F010-AC5:** A report can be requested for the last n days or months and downloaded.
