## Content

Une annonce médicale importante peut bouleverser les habitudes de toute la famille. Pour retrouver un peu de maîtrise, concentrez-vous sur les prochaines étapes et répartissez les tâches selon les disponibilités de chacun.

### Créer un point de repère

Rassemblez les rendez-vous, les coordonnées des professionnels et les documents utiles dans un endroit accessible. Notez les questions à poser et demandez qui contacter en cas de changement de symptômes ou de problème de traitement.

### Répartir l'aide

Demandez à la personne malade ce qu'elle souhaite déléguer. Les proches peuvent se répartir les transports, les repas ou les démarches, en tenant compte de leurs propres contraintes.

### Préserver les informations personnelles

Choisissez ensemble ce qui peut être partagé avec l'entourage ou l'employeur. Un assistant social de l'établissement peut guider les démarches administratives et les demandes d'aide.

Il n'est pas nécessaire d'anticiper toutes les étapes du parcours dès le premier jour.
